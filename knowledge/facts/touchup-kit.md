# Kit de retoque

## Presentación

La presentación incluye 5 sets. Cada set contiene un mini bote vacío para labial, un mini contenedor vacío para polvo con tamizador, una esponja triangular de tamaño completo y un mini bote recargable para spray.

## Contenido y usos

No incluye cosméticos: los recipientes se entregan vacíos. Permite preparar pequeñas cantidades de labial, polvo suelto, producto líquido compatible o spray compatible para retoques de maquilladores, novias, eventos, producciones, emprendimientos o uso personal.

## Modalidad comercial

Existe venta minorista y mayorista. El precio actual, mínimo mayorista y disponibilidad deben verificarse en la publicación o presupuesto vigente. Si la modalidad no aparece, Fred reúne la cantidad requerida y deriva a Isa.
