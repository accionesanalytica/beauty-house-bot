# Carga del mini spray

1. Retirar la tapa inferior.
2. Ubicar el orificio de carga.
3. Subir la base interna de silicona hasta el nivel correspondiente a la cantidad deseada.
4. Introducir cuidadosamente el producto por el orificio inferior.
5. Cerrar correctamente el orificio.
6. Recolocar la tapa inferior.
7. Comprobar el cierre antes de transportarlo.

No posee tubo interior y no se llena retirando el cabezal superior.
